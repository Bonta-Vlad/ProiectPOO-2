# Interfata TUI Baza de date Postgres
O interfață TUI pentru o bază de date Postgres.
Folosind libpqxx și FTXUI
## Build

```
mkdir build
cd build
cmake ..
make project
```

## Detalii 

libpqxx: https://github.com/jtv/libpqxx

FTXUI:   https://github.com/ArthurSonzogni/FTXUI

Singelton folosit în menu.cpp
